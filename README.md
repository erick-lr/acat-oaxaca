# Algoritmo Ciudadano de Alerta Temprana (ACAT v2026)

## 🚀 Descripción General
Herramienta inédita basada en software libre (Python) diseñada para la fiscalización preventiva y el control interno de las contrataciones públicas locales.

## 🛠️ Requisitos e Instalación
1. Tener instalado Python 3.10 o superior.
2. Descargar el archivo `acat.py` de este repositorio.
3. Ejecutar en terminal: `python acat.py`

## 📊 Escala del Semáforo
- 🟢 Verde: 0 a 29 Puntos (Riesgo Bajo).
- 🟡 Amarillo: 30 a 49 Puntos (Riesgo Moderado).
- 🔴 Rojo: 50 a 100 Puntos (Riesgo Crítico / Opacidad de Beneficiarios).
